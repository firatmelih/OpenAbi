OpenAbi 1.1.0 🥸

Abi got some upgrades.

New

  • Quick setup: OpenAbi finds VS Code, Cursor, Zed, Windsurf, Sublime Text, Nova, Terminal, iTerm, Ghostty and Warp on your Mac. Add them to folders in one click.
  • Finder toolbar button: a mustache button that opens the selection, or the current folder, in any of your apps. Add it with View ▸ Customize Toolbar…
  • Optional submenu: group all your apps under a single “OpenAbi ▸” item.
  • Automatic updates: no more downloading new versions by hand. OpenAbi tells you when an update is out and installs it for you.

Improved

  • Cleaner menu items: “Open in Visual Studio Code” instead of “Visual Studio Code — OpenAbi”.
  • Now installable with Homebrew (see the README).
